# Контур-77

Одиночная браузерная 3D-игра о ночной смене в промышленном городе 2087 года. В проекте есть две сборки из одних исходников. GitHub Pages отдаёт скрипты, стили, шрифты, изображения и звук отдельными файлами. Автономная сборка открывается двойным щелчком.

## Запуск на компьютере

Для разработки нужен Node.js 22 или новее. Сборка и тесты используют стандартную библиотеку Node.js.

~~~sh
node --test
node scripts/build.mjs
node scripts/serve.mjs
~~~

Откройте [локальную игру](http://127.0.0.1:8080/). После изменения исходников повторите сборку. Чтобы проверить сайт по адресу с именем репозитория, запустите сервер командой `node scripts/serve.mjs 8080 /kontur-77/` и откройте [версию в подпапке](http://127.0.0.1:8080/kontur-77/).

## Публикация на GitHub Pages

1. Загрузите исходники проекта в ветку `main` своего репозитория, включая скрытую папку `.github`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
3. Откройте **Actions → GitHub Pages → Run workflow** и укажите ветку `main`. Следующие отправки изменений в эту ветку запускают публикацию автоматически.

Workflow сначала выполняет тесты, собирает `dist/` и публикует содержимое этой папки. Ссылка на игру появится в результате задания **deploy**. Ресурсы загружаются относительно адреса игры, у каждого проекта свой офлайн-кеш. После сообщения «Можно играть офлайн» игру можно снова открыть по тому же адресу без подключения. [Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

## Автономная версия и старые сохранения

~~~sh
node scripts/build.mjs --standalone
~~~

Команда создаёт или обновляет **Kontur-77-3.3.html** в корне. Если открыть его в прежнем браузере по прежнему пути, игра сможет использовать сохранённые там профили. Для переноса на сайт в локальной игре нажмите **Esc → Сохранения и диагностика → Экспортировать JSON**. На сайте откройте нужный профиль, нажмите **Выбрать сохранение**, проверьте показанный баланс и нажмите **Применить сохранение**. Для каждого профиля нужен свой экспорт. Сохранения хранятся в браузере игрока.

## Структура проекта

| Папка | Содержимое |
|---|---|
| game/ | Игровые модули CommonJS. Точка входа — main.js |
| engine/ | Модули Three.js r180 |
| assets/ | Озвучка, звуковые эффекты, небо, шрифты и значок |
| site/ | HTML, CSS, загрузчик модулей и исходник сервис-воркера |
| scripts/ | Сборка и локальный HTTP-сервер |
| tests/ | Регрессионные тесты |
| licenses/ | Уведомления для Three.js и школьной части игры |
| dist/ | Сгенерированная версия для статического хостинга |

Редактируйте исходники в соответствующих папках. Каталог dist и автономный HTML создаются заново при сборке и исключены из Git.
